    How to cite

    1. Cite the publication listed above — use the BibTeX button next to it.
    2. For datasets, cite the Zenodo DOI so the exact version is preserved.
    3. For software, open the repository and click Cite this repository in the right sidebar.

    Code is released for research purposes only and is not a medical device. Human-subject data are anonymised and were collected with ethics committee approval; see each repository for details and licence.
